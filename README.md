# muse-usage
Muse usage data for a Scriptable widget (auto-updated)

Auto-updated Muse usage data for a Scriptable widget on iPhone.

- `usage.json` — latest usage snapshot (weekly % used, reset time, additional tokens)
- `update_usage.py` — updater that runs on Muse's VM every 15 minutes
- Widget script: `muse-usage-widget.js` (paste into the Scriptable app)
